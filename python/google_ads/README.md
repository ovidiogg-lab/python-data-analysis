# Google Ads - Python Scripts

Scripts reutilizables para análisis de campañas de Google Ads.

## Archivos
- `obtener_metricas_basicas.py`  
  Calcula clics, impresiones, CTR y CPC desde un DataFrame.

- `reglas_alertas.py`  
  Detecta campañas con bajo CTR o CPC alto.

## Uso
Copiar el script o importar funciones según necesidad.
